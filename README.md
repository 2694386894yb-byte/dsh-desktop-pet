# DeepSeek / DSH 桌宠（奶蛙形象）

常驻 macOS 菜单栏刘海右侧留白的 3D 形象。造型是网上那只 **奶蛙**：黄色梨形身体、大块奶油色肚皮、
凸起的圆眼（眼白泛绿、小黑点瞳孔）、深橄榄褐色的手脚，招牌动作是 **捂着肚子狂笑**。
它读取 DSH 本机 session projection cache：干活时发抖变琥珀色，**出了新结果就捧腹大笑并整体放大**。

## 构建和启动

```bash
bash scripts/build.sh
open "build/DeepSeek 桌宠.app"
```

右键形象或点状态栏图标可打开菜单。支持演示动画、暂停/继续 DSH 监听、显示/隐藏、调整大小和位置、点击穿透、开机启动和退出。

## 动作表

| 你在 DSH 里 | 奶蛙的反应 |
|---|---|
| 空闲 | 慢呼吸、偶尔眨眼、左右张望，绿眼睛 |
| 正在干活 | 身体快速小幅发抖、眯眼变琥珀色、肚子外面转起金色光环 |
| **出了新结果** | **先弹一下 → 双手捂肚、张嘴大笑、笑到发抖，同时整个形象放大 1.28 倍约 1.3 秒**，并撒星星、弹气泡 |
| 很久没动静 | 闭眼打盹，颜色变暗 |
| 被点一下 | 短促地笑两秒（奶蛙梗的「点一下就狂笑」），气泡里冒「哈哈哈哈哈！」 |

放大是真的把**窗口一起放大**：相机视角和距离都不变，所以窗口高一倍、画出来的奶蛙就大一倍，
放大期间左边缘不越过原位——右边就是刘海，压上去会被物理挖空。

## 信号来源

默认只读 `~/.dsh/storages/session_projcache/sessions/*.json`。以 DSH 投影中的 `sessionStats.openStep`、
`turnBoundary.lastStepBoundary.kind` 和 `turnOutline.turns[].response` 判断工作与新结果；
同一会话轮次只庆祝一次（缓存每步都会被重写，不去重会疯狂放烟花）。
子代理会话的标题是 DSH 内部提示词，一律不理会。可以用 `--sessions-dir` 指定测试目录。

## 验证

```bash
bash scripts/verify.sh              # 全跑
SKIP_E2E=1 bash scripts/verify.sh   # 跳过需要录屏权限的截图步骤
```

脚本执行：构建 → 42 项纯逻辑测试 → 窗口层级/刘海避让/取景自检（**按渲染像素**量形象大小）→
四种心情渲染图 → 合成会话「干活中 → 出结果」端到端截图。
`scripts/make-fake-session.py` 可以生成测试用的 DSH 投影。

## 隐私与限制

只读 DSH 本地会话投影，不修改会话、不联网、不与 Codex 交互。
投影格式属于 DSH 内部实现，若其字段改变，监听可能需要更新（解析失败只会「这一拍没信号」，不会崩）。
锁屏行为、多屏跟随和功耗尚未实测。
